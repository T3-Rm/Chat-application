
# Python Chat Application

## Project Overview
A beginner-friendly chat application built using Python sockets.
It allows multiple users to exchange messages in real time.

## Features
- Multiple clients can connect to a server.
- Real-time message exchange.
- Displays sender names and timestamps.
- Supports graceful disconnection.
- Uses Python threading to handle multiple clients.

## Technologies Used
- Python 3
- Socket programming
- Threading
- Visual Studio Code

## Project Structure
- server.py - Starts the chat server.
- client.py - Connects users to the chat.
- screenshots/output.png - Screenshot of the working application.

## How to Run

1. Install Python 3.
2. Open the project folder in VS Code.
3. Open a terminal in the project folder.
4. Start the server:

   python server.py

5. Open a second terminal and start the first client:

   python client.py

6. Open a third terminal and start the second client:

   python client.py

7. Enter a different name in each client.
8. Send messages between the two clients.
9. Type exit to disconnect a client.
